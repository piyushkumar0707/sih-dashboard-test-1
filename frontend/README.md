# Travira frontend

This directory contains the React single-page application built with Vite. From the repository root, use `npm --prefix frontend install`, `npm --prefix frontend run start`, and `npm --prefix frontend run build`. The Vite development server uses port 3000; set `VITE_API_BASE_URL` to the backend URL when it is not `http://localhost:5000`.

The `test` script is a placeholder and does not run a frontend test suite yet.
